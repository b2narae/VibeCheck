# Code of conduct

## The short version

Be decent. This is a small project about a pixel horse; nothing here is worth
being unpleasant to someone over.

## What is expected

- Assume the person you are replying to is acting in good faith.
- Critique code, not people. "This misses the case where the log is empty" is
  useful; "this is sloppy" is not.
- Accept that maintainers may decline a change. A "no" to a patch is not a
  judgement of the person who wrote it.
- English and Korean are both welcome in issues and pull requests. Neither is
  anyone's obligation to write well.

## What is not

Harassment, personal attacks, demeaning comments, or unwelcome attention —
about anyone's identity, background, or experience level. Deliberately
derailing discussions. Publishing someone's private information.

Beginners are explicitly welcome. "Add your own animal" exists because a
two-minute pull request is a good first one, and questions about it are not an
imposition.

## Scope

This applies in issues, pull requests, commit messages and any other space
this project uses.

## Reporting

Raise it with the maintainer through
[an issue](https://github.com/b2narae/VibeCheck/issues) if it can be discussed
publicly. If it cannot, open an issue saying only that you would like a private
channel, and one will be arranged.

Reports are handled by the maintainer, who may edit, delete or lock content and
block accounts. There is no committee; this is one person's project.
